# Archive

Documents whose work is done, kept rather than deleted because they are evidence of
how something was decided or where it came from.

**Nothing here decides anything, and no live document depends on one for a
decision.** A document that a charter or a Spec still leans on for a ruling belongs
in the working set.

**Citation for provenance is a different thing and is allowed.** `weaver-spu-Spec`
cites the salvage survey as its quarry map, for where a mechanic came from, and that
is a fact about history rather than a dependency on an open question. The test is
whether the citing document would have to change if the archived one were wrong.

`handoffs/` holds seat-to-seat handoffs whose acts are done. A handoff is spent by
construction: it describes where the work sat at a commit, addressed to a session that
has since done it, so it ages out rather than being superseded.

Each carries an ARCHIVED status line saying when it landed here and why.
